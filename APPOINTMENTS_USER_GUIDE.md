# 📅 Guide Utilisateur - Gestion des Rendez-vous

## 🚀 Accès Rapide

1. Connectez-vous au dashboard médical
2. Cliquez sur **"Rendez-vous"** dans le menu latéral (icône calendrier)
3. Vous arrivez sur la page de gestion des rendez-vous

---

## 📋 Vue d'ensemble

La page affiche un **tableau complet** de tous vos rendez-vous avec :

| Colonne | Description |
|---------|-------------|
| **Date/Heure** | Date et heure du rendez-vous |
| **Patient** | Nom du patient |
| **Motif** | Raison de la consultation |
| **Statut** | État actuel (à venir, terminé, annulé) |
| **Contact** | Numéro de téléphone |
| **Actions** | Boutons d'action (voir, modifier, annuler) |

---

## ➕ Créer un Nouveau Rendez-vous

### Étapes
1. Cliquez sur le bouton bleu **"Nouveau Rendez-vous"** en haut à droite
2. Une fenêtre s'ouvre avec un formulaire

### Remplir le Formulaire

#### 1. Sélectionner le Patient
- **Option A** : Tapez le nom dans la barre de recherche
  - Les résultats apparaissent automatiquement
  - Cliquez sur le patient souhaité
- **Option B** : Saisissez manuellement si le patient n'existe pas encore

#### 2. Choisir la Date et l'Heure
- Cliquez sur le champ **Date** → Sélectionnez la date dans le calendrier
- Cliquez sur le champ **Heure** → Choisissez l'heure

#### 3. Renseigner les Détails
- **Email** : Email du patient (optionnel)
- **Téléphone** : Numéro de téléphone (optionnel)
- **Motif** : Raison de la consultation (ex: "Consultation de suivi")
- **Type de consultation** : Choisissez parmi :
  - Consultation
  - Contrôle
  - Suivi
  - Urgence
  - Téléconsultation
- **Durée** : Sélectionnez 15, 30, 45 ou 60 minutes
- **Notes privées** : Informations internes non visibles par le patient

#### 4. Valider
- Cliquez sur **"Créer le rendez-vous"**
- ✅ Une notification verte confirme la création
- La fenêtre se ferme automatiquement
- Le nouveau rendez-vous apparaît dans la liste

---

## 👁️ Consulter les Détails d'un Rendez-vous

1. Trouvez le rendez-vous dans le tableau
2. Cliquez sur l'icône **œil bleu** (👁️) dans la colonne "Actions"
3. Une fenêtre s'ouvre avec toutes les informations :
   - Statut du rendez-vous
   - Informations patient (nom, email, téléphone)
   - Date, heure et durée
   - Motif et type de consultation
   - Notes privées
   - Historique (création, modification, annulation)
4. Cliquez sur **"Fermer"** ou **"Modifier"** si vous voulez faire des changements

---

## ✏️ Modifier un Rendez-vous

### Méthode 1 : Depuis la Liste
1. Trouvez le rendez-vous dans le tableau
2. Cliquez sur l'icône **crayon gris** (✏️) dans la colonne "Actions"

### Méthode 2 : Depuis les Détails
1. Ouvrez les détails du rendez-vous (👁️)
2. Cliquez sur le bouton **"Modifier"** en bas

### Faire les Modifications
1. La fenêtre de modification s'ouvre
2. Modifiez les champs souhaités :
   - Statut (à venir, en cours, terminé, annulé)
   - Date et heure
   - Motif
   - Type de consultation
   - Durée
   - Notes privées
3. Cliquez sur **"Enregistrer"**
4. ✅ Une notification verte confirme la modification

---

## ❌ Annuler un Rendez-vous

1. Trouvez le rendez-vous dans le tableau
2. Cliquez sur l'icône **croix rouge** (❌) dans la colonne "Actions"
3. Une fenêtre de confirmation apparaît avec le message :
   > "Êtes-vous sûr de vouloir annuler le rendez-vous de [Nom Patient] prévu le [Date] à [Heure] ?"
4. **Deux options** :
   - **"Oui, annuler"** → Le rendez-vous est annulé
   - **"Non, conserver"** → Rien ne change
5. Si vous confirmez, ✅ une notification verte indique que le rendez-vous a été annulé
6. Le statut passe à "Annulé" (badge rouge)

**Note** : L'annulation ne supprime pas le rendez-vous, il reste visible dans l'historique.

---

## 🔍 Rechercher un Rendez-vous

### Barre de Recherche
1. Localisez la barre de recherche en haut de la page
2. Tapez l'un des éléments suivants :
   - **Nom du patient** (ex: "Dupont")
   - **Numéro de téléphone** (ex: "0612345678")
   - **Email** (ex: "dupont@email.com")
   - **Motif** (ex: "consultation")
3. La liste se filtre **automatiquement** pendant que vous tapez
4. Pour tout réafficher, effacez le champ de recherche

---

## 🎯 Filtrer par Statut

1. Localisez le menu déroulant **"Filtrer par statut"** à côté de la barre de recherche
2. Cliquez dessus et choisissez :
   - **Tous les statuts** (par défaut)
   - **À venir** → Affiche seulement les RDV futurs
   - **Terminé** → Affiche seulement les RDV passés
   - **Annulé** → Affiche seulement les RDV annulés
   - **En cours** → Affiche seulement les RDV en cours
3. La liste se met à jour instantanément

---

## 🔀 Trier par Date

1. Localisez le bouton avec l'icône **flèches haut/bas** (⬍⬍)
2. Cliquez dessus pour inverser l'ordre de tri :
   - **Par défaut** : Les plus récents en haut (décroissant)
   - **Inversé** : Les plus anciens en haut (croissant)
3. La liste se réorganise immédiatement

---

## 🎨 Comprendre les Badges de Statut

| Badge | Couleur | Signification |
|-------|---------|---------------|
| **À venir** | 🟢 Vert | Rendez-vous programmé dans le futur |
| **En cours** | 🟡 Jaune | Rendez-vous en train de se dérouler |
| **Terminé** | 🔵 Bleu | Rendez-vous passé et terminé |
| **Annulé** | 🔴 Rouge | Rendez-vous annulé |

## 💡 Astuces et Bonnes Pratiques

### ✅ Bonnes Pratiques

1. **Vérifiez toujours les informations** avant de créer un RDV
2. **Utilisez les notes privées** pour des informations médicales importantes
3. **Annulez les RDV** plutôt que de les supprimer (pour garder l'historique)
4. **Filtrez et recherchez** pour trouver rapidement un RDV
5. **Consultez les détails** avant de modifier un RDV

### 🚀 Raccourcis Clavier

| Raccourci | Action |
|-----------|--------|
| `Tab` | Naviguer entre les champs/boutons |
| `Enter` | Valider/Activer |
| `Esc` | Fermer une fenêtre |
| `Ctrl + Shift + P` | Afficher les statistiques de performance (console) |

## ❓ Questions Fréquentes

### Q1 : Puis-je supprimer définitivement un rendez-vous ?
**R** : Non, pour conserver l'historique médical, vous pouvez seulement **annuler** un rendez-vous. Il restera visible mais avec le statut "Annulé".

### Q2 : Comment voir tous les RDV d'un patient ?
**R** : Utilisez la **barre de recherche** et tapez le nom du patient. Tous ses rendez-vous (passés, à venir, annulés) s'afficheront.

### Q3 : Puis-je créer un RDV pour un patient qui n'existe pas encore ?
**R** : Oui ! Si le patient n'apparaît pas dans l'autocomplete, vous pouvez **saisir manuellement** son nom, email et téléphone dans le formulaire.

### Q4 : Que signifie "Notes privées" ?
**R** : Ce sont des informations **internes** visibles uniquement par les médecins. Le patient ne les voit pas.

### Q5 : Combien de temps puis-je programmer un RDV à l'avance ?
**R** : Il n'y a pas de limite. Vous pouvez programmer un rendez-vous plusieurs mois à l'avance.

### Q6 : Les modifications sont-elles sauvegardées automatiquement ?
**R** : Non, vous devez toujours cliquer sur **"Enregistrer"** ou **"Créer"** pour valider les changements.

### Q7 : Puis-je voir qui a créé ou modifié un RDV ?
**R** : Oui, dans les **détails du RDV**, en bas vous verrez :
- Date de création
- Date de dernière modification
- Date d'annulation (si applicable)

## 🆘 Problèmes Courants

### Le tableau est vide
**Solution** :
1. Vérifiez que vous n'avez pas de filtres actifs
2. Essayez de vider la barre de recherche
3. Sélectionnez "Tous les statuts" dans le filtre
4. Actualisez la page (F5)

### Je ne trouve pas un patient dans l'autocomplete
**Solution** :
1. Vérifiez l'orthographe
2. Essayez de chercher par téléphone ou email
3. Si le patient n'existe pas, saisissez manuellement son nom

### Une notification d'erreur apparaît
**Solution** :
1. Lisez attentivement le message
2. Vérifiez que tous les champs requis sont remplis
3. Vérifiez votre connexion internet
4. Réessayez dans quelques secondes
5. Si l'erreur persiste, contactez le support

### Le bouton "Créer" ne fait rien
**Solution** :
1. Vérifiez que les champs **obligatoires** (marqués *) sont remplis
2. Attendez que le bouton ne soit plus en état "Création..."
3. Regardez s'il y a un message d'erreur en rouge dans le formulaire
