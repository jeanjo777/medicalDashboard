# 🚀 Quick Start - Analytics Dashboard

## Accès Rapide

```bash
# URL de la page
http://localhost:5173/analytics-advanced
```

## 📊 Les 7 Onglets

1. **Vue d'ensemble** - Tous les graphiques et stats
2. **Prédictions IA** - Forecast avec intervalles de confiance
3. **Corrélations** - Analyse corrélations (placeholder)
4. **Segmentation** - Segmentation patients (placeholder)
5. **Alertes IA** - 3 alertes par sévérité
6. **Comparatif** - Comparaisons temporelles (placeholder)
7. **Rapports** - Génération et téléchargement

## ⚡ Actions Rapides

### Filtrer les Données
1. Click "Filtres Avancés"
2. Sélectionner critères (dates, département, médecin...)
3. Click "Appliquer"

### Voir Prédictions
1. Onglet "Prédictions IA"
2. Consulter forecast 3 mois
3. Lire insights automatiques

### Consulter Alertes
1. Onglet "Alertes IA"
2. 3 alertes classées (Rouge/Orange/Jaune)

### Exporter
1. Hover "Exporter" (coin haut droite)
2. Choisir format (CSV/JSON/TXT)

## 📱 Responsive

- Mobile: KPIs 1 col, onglets icônes
- Tablette: KPIs 2 cols
- Desktop: KPIs 4 cols
