## 🎨 CONVENTIONS & LÉGENDE

### Symboles ASCII

```
┌─────────┐  = Container/Card
│         │
└─────────┘

[Button]     = Bouton cliquable
<Input>      = Champ de saisie
{Icon}       = Icône
(Dropdown)   = Menu déroulant
...          = Contenu répétitif
---          = Séparateur horizontal
|||          = Séparateur vertical
```

### Annotations

```
[ACTION]     = Action interactive
{STATE}      = État du composant
(INFO)       = Information contextuelle
<REQUIRED>   = Champ obligatoire
```
